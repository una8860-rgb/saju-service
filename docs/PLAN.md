# 사주 운세 서비스 계획서 (초안)

> 작성일: 2026-10-12 · 상태: 기획 단계

## 1. 서비스 개요

| 항목 | 내용 |
|---|---|
| 한 줄 소개 | 정확한 만세력 계산 위에, 그림으로 한눈에 읽히는 사주풀이 |
| 핵심 가치 | ① **정확성** — 절기·시간 보정까지 반영한 만세력 ② **시각화** — 원국표·오행 차트·대운 타임라인·일주 캐릭터 ③ **쉬운 해석** — 전문용어 대신 키워드와 요약 |
| 디자인 레퍼런스 | [점신](https://www.jeomsin.co.kr/) — 화이트 카드, 넉넉한 여백, 라인 아이콘 + 포인트 컬러 |
| 대상 | 20–40대, 모바일 중심 사용자 |

## 2. 기능 범위

### MVP (1차 출시)
1. **사주 입력** — 이름, 성별, 생년월일, 양/음력(윤달), 태어난 시각(모름 허용), **출생지(시/도 → 도시, 기본 서울)** — 출생지 경도로 시간을 보정
2. **평생사주 결과** — 아래 3장의 결과 화면 구성
3. **만세력 조회** — 날짜별 연·월·일·시 간지, 절기 표시

### 2차
- 오늘의 운세(일진 기반), 올해 운세(세운), 월별 운세 캘린더
- 궁합(두 사람 원국 비교)
- 결과 공유 이미지(SNS 카드), 회원 저장

## 4. 디자인 원칙 (점신 레퍼런스 분석)

- **레이아웃**: PC에서는 좌측 브랜드 패널 + 중앙 모바일 폭(약 480px) 앱 컬럼. 모바일에서는 앱 컬럼만 노출 → `components/layout/AppShell`
- **배경/카드**: 연회색 배경 위 흰 카드, 둥근 모서리, 얕은 그림자
- **타이포**: 섹션 머리말(작은 회색) + 제목(굵은 검정) 2단 구성
- **아이콘**: 검정 라인 + 노랑 포인트 일러스트 아이콘, 원형 연한 배경
- **목록 패턴**: ① 3열 아이콘 그리드 ② 아이콘 + 제목 + 설명 리스트 행 ③ 2×2 타일
- **강조**: 파랑 포인트 텍스트, 노랑 배지(예: "NEW", "무료")

레퍼런스 캡처: `docs/design/reference/jeomsin-home-full.png`

## 5. 만세력·풀이 엔진 설계

```
입력값 ──▶ [lib/manseryeok] ──▶ 사주 원국 ──▶ [lib/analysis] ──▶ 분석 결과 ──▶ [lib/interpret] ──▶ 화면 데이터
           음양력 변환·시간보정·      (4주 8자,       오행 점수·십신·        (수치·태그)       content/ 텍스트
           절기·4주·대운              대운)           신강약·합충·신살                            매핑
```

- **만세력**(계산): 결과가 하나로 정해지는 부분. 테스트로 정확성을 보장 → 상세 규칙은 `docs/manseryeok/SPEC.md`
- **분석**(판단): 오행 점수, 십신 분포, 신강/신약, 용신, 합·충·형·파·해, 신살
- **풀이**(문장): 분석 결과를 키로 `content/` 텍스트를 조합. 코드와 문장을 분리해 비개발자도 문장을 수정할 수 있게 한다.

### 풀이 콘텐츠 분량 (예상)
| 폴더 | 단위 | 개수 |
|---|---|---|
| `content/ilgan` | 일간(10천간) 기본 성향 | 10 |
| `content/ilju` | 60일주 상세 | 60 |
| `content/sipsin` | 십신 과다/부족/부재 | 10 × 3 |
| `content/ohaeng` | 오행 과다/부족 | 5 × 2 |
| `content/daeun` | 대운 십신별 흐름 | 10 |
| `content/sinsal` | 주요 신살 | 약 15 |
| `content/themes` | 재물·애정·건강·직업 조합 문장 | 테마별 |

> ⚠️ 풀이 문장은 **직접 작성한 것만** 사용한다. 다른 사이트(운세의신 등)에서 크롤링한 문장은 저작권 문제가 있으므로 문장 구성·항목 구성을 참고하는 용도로만 쓴다.

| `public/images/banners` | 홈 배너 | 3–5 | MVP |

- **그림체**: [Canva 띠별 운세 템플릿](https://www.canva.com/ko_kr/templates/EAF8AmcUYrE/) 느낌 — 둥근 얼굴만 그린 동물, 단일 갈색 외곽선, 파스텔 단색, 분홍 볼터치. 상세 규칙은 `docs/design/ILLUSTRATION.md`
- 그림체만 참고하고 Canva 그림 자체는 쓰지 않는다(라이선스상 Canva 밖 단독 사용 불가) → 같은 스타일로 새로 제작
- 색 조합: 본문은 점신식 흰 카드, 홈 히어로·공유 카드는 레퍼런스의 남색 배경
- 형식: 아이콘은 SVG(색 토큰 적용), 캐릭터·배너는 WebP
- 간지 글자(甲乙丙…)는 이미지가 아니라 **텍스트 컴포넌트**(`GanjiChip`)로 그려서 색·크기를 코드로 제어

## 7. 기술 스택 (제안)

| 영역 | 선택 | 이유 |
|---|---|---|
| 프레임워크 | Next.js (App Router) + TypeScript | 결과 페이지 SEO, API 라우트 같이 운영 |
| 스타일 | Tailwind CSS + `styles/tokens.css` | 오행 컬러·카드 스타일 토큰화 |
| 만세력 | `lunar-javascript` + 자체 보정 레이어 | 절기·간지 계산 검증된 라이브러리, 한국 시간 보정은 직접 구현 |
| 차트 | Recharts (레이더·라인·막대) | 가벼움, React 친화 |
| 테스트 | Vitest | 만세력 경계 케이스 대량 검증 |

## 8. 일정 (단계별)

|---|---|---|
