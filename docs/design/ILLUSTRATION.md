# 일러스트 스타일 가이드

레퍼런스: [Canva 띠별 운세 템플릿](https://www.canva.com/ko_kr/templates/EAF8AmcUYrE/) → `reference/canva-zodiac-illust.png`

> ⚠️ **그림체만 참고한다.** Canva 템플릿 속 그림은 Canva 라이선스 아래에서 Canva 디자인 안에서만 쓸 수 있어, 따로 떼어내 서비스 화면에 넣을 수 없다. 같은 느낌으로 **직접(또는 외주로) 새로 그린 그림**만 사용한다.

## 레퍼런스에서 뽑은 특징

| 요소 | 규칙 |
|---|---|
| 구도 | **얼굴(머리)만**, 정면, 몸통 없음 |
| 형태 | 둥근 덩어리 위주, 각진 곳 없음. 머리 비율이 크고 귀·뿔 같은 특징은 작고 단순하게 |
| 외곽선 | 진한 갈색/짙은 회색 단일 선, 굵기 일정(512px 기준 약 8–10px), 끝은 둥글게 |
| 채색 | 파스텔 단색 면 + 아주 옅은 그림자 1단계. 그라데이션·질감 없음 |
| 얼굴 | 점 눈(작은 검정 원), 작은 입, **분홍 볼터치** |
| 표정 | 기본은 살짝 웃음. 결과 화면에서는 기쁨·보통·걱정 3종 변형 |
| 배경 | 투명 PNG/WebP. 서비스 화면에서는 흰 카드 또는 원형 연한 배경 위에 배치 |

## 색

- 캐릭터: 동물 고유색을 파스텔로 (쥐=회색, 소=갈색, 호랑이=노랑+줄무늬, 토끼=흰색, 용=연두 …)
- 띠 캐릭터의 **포인트 소품 색은 그 해 오행 색**으로 맞춘다 (예: 甲辰년 용 → 木 초록 소품)
- 브랜드 배경: 레퍼런스의 **남색**을 홈 히어로·공유 카드 배경에 사용하고, 본문 영역은 점신처럼 흰 카드 유지

## 현재 제작본

- 12띠 얼굴 SVG 1차본: `public/images/zodiac/*.svg`
- 생성 스크립트: `scripts/illust/gen_zodiac.py` (색·선 굵기·눈 크기 등 공통값을 상단 상수로 관리 → 수정 후 다시 실행)
- 미리보기: `docs/design/preview/zodiac.html` (브라우저로 열기)

## 파일 규격

- 캐릭터: 1024×1024 원본(PSD/AI 보관), 서비스용 512×512 WebP, 투명 배경
- 아이콘: SVG, 선 색은 `currentColor`로 두어 코드에서 색 지정
- 원본 파일은 `public/`이 아닌 별도 디자인 저장소(또는 `docs/design/source/`)에 보관
