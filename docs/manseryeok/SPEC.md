# 만세력 계산 규칙 & 검증 계획

사주풀이의 정확도는 **원국(8글자)이 맞는가**에서 결정된다. 아래 규칙을 `src/lib/manseryeok`에 구현하고, 각 규칙마다 `tests/manseryeok`에 경계 케이스 테스트를 둔다.

## 1. 계산 순서

```
입력(양/음력, 윤달, 시각, 출생지)
  ① 음력 → 양력 변환                    calendar.ts
  ② 시간 보정: 서머타임 → 표준시 → 출생지 경도   timeCorrection.ts, locations.ts
  ③ 연주: 입춘 절입 시각 기준              pillars.ts
  ④ 월주: 12절(節) 절입 시각 기준           solarTerms.ts / pillars.ts
  ⑤ 일주: 60갑자 순환 (자시 정책 반영)      pillars.ts
  ⑥ 시주: 일간 기준 시두법                 pillars.ts
  ⑦ 대운: 순행/역행, 대운수                 daeun.ts
```

## 2. 규칙 상세

| 규칙 | 내용 | 흔한 오류 |
|---|---|---|
| 연 경계 | 1월 1일·설날이 아니라 **입춘 절입 시각** | 1–2월생 띠가 틀림 |
| 월 경계 | 매월 1일이 아니라 **절기(입춘·경칩·청명…) 절입 시각** | 절입일 당일 출생자 월주 오류 |
| 경도 보정 | 한국 표준시(동경 135°) ↔ **입력받은 출생지 경도**. 보정(분) = (경도 − 135) × 4 → 서울 −32분, 부산 −24분 (`data/locations/kr-cities.json`) | 지역 무시하고 일괄 −30분 처리 |
| 표준시 변경 | 1954.3.21–1961.8.9 기간은 동경 127.5° 표준시 사용 | 해당 기간 보정을 이중 적용 |
| 서머타임 | 1948–1951, 1955–1960, 1987–1988 시행 기간 -1시간 | 87·88년생 시주 오류 |
| 자시 | 보정 후 23:00부터 다음 날 일주 (아래 4절) | 일주가 하루 밀림 |
| 윤달 | 음력 입력 시 평달/윤달 구분 필수 | 윤달생 날짜 오류 |
| 시각 모름 | 시주 없이 6글자로 분석, 화면에 "시주 미상" 표시 | 임의로 자시 채움 (운세의신 방식 — 피할 것) |
| 대운 방향 | 양년생 남 / 음년생 여 = 순행, 반대는 역행 | |
| 대운수 | 출생 ~ 다음(역행은 이전) 절입까지 일수 ÷ 3, 반올림 | |

## 3. 자시(子時) 처리 — 결정

국내 만세력 사이트·앱 조사 결과를 따라 아래처럼 정한다.

| 항목 | 결정 | 근거 |
|---|---|---|
| 자시 범위 | **보정된 시각 기준 23:00–01:00** (서울 출생이면 시계 시각으로 약 23:32–01:32) | 국내 앱 대부분이 자시를 23:30–01:30(시계 시각)으로 설정. 출생지 경도 보정을 하므로 지역별로 정확히 계산 |
| 기본값 | **야자시/조자시 구분 안 함** — 자시가 시작되면 일주도 다음 날로 넘어감 | 전통 방식이자 다수 사이트 기본값(사주팔콤 등도 야자시 옵션 기본 해제). 야자시를 쓰면 시주가 시두법과 맞지 않는 조합이 생기는 문제 |
| 옵션 | 결과 화면 "고급 설정"에 **야자시 적용** 토글 제공 | 야자시 학파 사용자 대응 |
| 경계 안내 | 보정 시각이 자시 경계 ±15분 안이면 결과에 "경계 출생 — 해시/자시 사주도 확인해 보세요" 안내와 비교 보기 제공 | 출생 기록 시각 자체의 오차 대응 |
| 균시차 | 기본 미적용, 고급 설정 옵션 | 대부분 앱이 미적용. 최대 ±16분 차이 |

```
예) 서울 출생, 1990-05-15 23:40 (시계 시각)
  → 서머타임 해당 없음 → 경도 보정 −32분 → 23:08
  → 자시 범위(23:00~) → 기본값: 일주 = 5월 16일, 시주 = 16일 일간 기준 자시
  → 야자시 옵션 ON: 일주 = 5월 15일, 시주 = 16일 자시
```

## 4. 출생지 입력

- 입력 폼: **지역 검색**(예: "나주") 또는 **시/도 → 시·군** 2단 선택, 기본값 서울
- 전국 **17개 시도 · 167개 시·군** (`data/locations/kr-cities.json`)
  - 시·군: 통계청 2018 행정구역 경계의 면적 중심점 경도 (`scripts/data/build_cities.py`로 생성)
  - 특별시·광역시 자치구 지역: 시청 좌표 하나로 통합 (구 사이 경도 차이 1분 내외), 소속 군(기장·달성·군위·강화·옹진·울주)은 별도
  - 2018 이후 변경 반영: 군위군 경북 → 대구(2023)
- 해외 출생(2차): 국가·도시 검색 → 해당 시점의 표준시(UTC 오프셋)와 경도로 보정
- 출생지는 결과 화면 상단 프로필에 "서울 출생 · 보정 −32분"처럼 표시해 계산 근거를 보여준다

## 5. 데이터 소스

- **절기 시각**: 한국천문연구원(KASI) 천문력 기준으로 1900–2100년 테이블을 `data/solar-terms/`에 생성 (`scripts/`로 생성·검증)
- **음양력 변환**: KASI 음양력 정보 API로 라이브러리 결과를 대조 검증
- **라이브러리**: `lunar-javascript`는 중국 기준(UTC+8)이므로, **보정된 한국 시각을 넣은 뒤** 간지만 계산하는 용도로 사용

- **출생지 경도**: `data/locations/kr-cities.json`
